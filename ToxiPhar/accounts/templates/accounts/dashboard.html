Toxicity screen

Draw the molecule's structure for the most reliable prediction. The editor below supports every standard drug-design tool: single/double/triple/aromatic bonds, any atom or element, charges, R/S wedge/dash stereochemistry, E/Z double bonds, R-groups, S-groups, and more. If you don't have a drawing, you can paste a SMILES string instead, or enter a chemical formula (e.g. C9H8O4) — either will load into the same editor so you can check the structure before predicting. Isomers (different R/S or E/Z forms), isotopes, and multi-component structures (salts or mixtures) are all fully supported. Note that a formula describes composition only, not connectivity, so the editor makes a best-effort structure guess from it — for an exact isomer, draw the structure or paste a SMILES string instead.
